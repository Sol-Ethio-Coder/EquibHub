# EquibHub - Workplace Savings

A complete web application for managing a 6-member EQUIB (rotating savings) group with payment verification, bank details, and admin dashboard.

## Features

- ✅ User Authentication (up to 6 members)
- ✅ Mandatory Screenshot Upload for contributions
- ✅ Bank Account Management
- ✅ Admin Dashboard with Verification
- ✅ Dark/Light Mode
- ✅ Responsive Design
- ✅ Session Management
- ✅ Export Reports (CSV/JSON)

## Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. First user becomes admin automatically

## Tech Stack

- HTML5
- CSS3 (Animations, Glassmorphism)
- JavaScript (ES6+)
- IndexedDB (Local Storage)
- Chart.js
